# Hyphenation pattern sources

`niori-pdf-hyphen-data.el` is generated by `../gen_hyphen.py` from the
upstream pattern files in this directory. The upstream files are retained
verbatim, including their embedded copyright and license headers.

The SHA-256 checksums are recorded in `SOURCES.lock`.

## Migration from the legacy pattern files

The four legacy source files previously used by niori-pdf were replaced
with maintained hyph-utf8 sources:

- `ushyph.txt` → `hyph-en-us.tex`
- `dehyphn.txt` → `hyph-de-1996.tex`
- `frhyph.txt` → `hyph-fr.tex`
- `gbhyph.txt` → `hyph-en-gb.tex`

The runtime language identifiers remain unchanged. The generated data now
derives from the pinned upstream sources listed above.

## Provenance notes

- `hyph-en-us.tex` identifies Gerard D.C. Kuiken and permits copying and
distribution, with or without modification, without royalty, provided the
copyright and permission notices are preserved.
- `hyph-de-1996.tex` is the 1996-reformed-orthography German set retained for
backward compatibility. Its header contains the complete author list and MIT
license.
- `hyph-fr.tex` contains the Flipo, Gaulle, and Reutenauer attribution and MIT
license.
- `hyph-en-gb.tex` contains the Wujastyk and Toal attribution and MIT license.
Its header distinguishes the Oxford University Press source word list (not
redistributed here) from the resulting pattern file, which may be distributed.
- The Spanish patterns cover Spanish varieties sharing RAE/ASALE orthography;
the Portuguese patterns cover European and Brazilian Portuguese.
- The Russian source includes explicit `\hyphenation{...}` exceptions;
these are included in the generated data.

## Rebuild and verify

From the repository root, run `python3 tools/gen_hyphen.py` to regenerate the
Elisp data, then `python3 tools/gen_hyphen.py --check` to verify byte-identical
reproducibility.

## Where the runtime hooks in

`niori-pdf-hyphen.el` consumes `(LEFTMIN RIGHTMIN PATTERNS EXCEPTIONS)`
per language. See `../gen_hyphen.py` for the exact transformation from
the upstream source files to the generated Elisp data, and
`../README.md` ("Extending") for instructions on adding a language.
